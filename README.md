# WannaPoop
A lovely little program that pretends to be malware, but is just Tkinter. Otherwise known as `canimakeamalwarequestion.py`, a reference to Project Hail Mary, where Rocky says 'question' after a question.

## Do you WannaPoop?
It is not a real malware, because if I don't say that someone will actually cry. That will probably be me. I am but an innocent student.

## Warning

Do not run this with 300,000,000 windows. If you do, don't sue me.

- I did 400 and Windows started putting weird black shadows on them. Therefore I have set it to less. Although to be fair I do use a slightly old HP laptop, so if you have a well oiled PC setup you could likely handle a bajillion windows. But don't do that.
- I also tried this on a school computer, and 300 gave it the same black shadows. I'm not sure about the specs, but its on of those ThinkCentre things.

Contains super hilarious messages that will knock your entire feet off, let alone socks. I know. I'm really funny. There's also random bits of Chinese, Arabic, and Russian, and copy pasted pieces of Rust code from who knows what. Its supposed to be scary, apparently.
